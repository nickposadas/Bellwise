About this demo

This is sample hotel data. AI review is simulated by templates in this browser — no live PMS, POS, or AI model is connected. The role selector changes what you see; it is not a security or permission control.

Changes you make are saved to this browser's local storage only, so refreshing keeps your work. This is not a shared or production database — nothing here is visible to any other user or device, and closing your browser's private-data settings will clear it.
